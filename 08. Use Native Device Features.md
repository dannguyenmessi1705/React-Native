# Sử dụng các tính năng có sẵn của thiết bị (Camera, Location, Microphone, ...)
## 1. Giới thiệu
Trong ứng dụng React Native, chúng ta có thể sử dụng các tính năng có sẵn của thiết bị như Camera, Location, Microphone, ...

Để tham khảo thêm, xem tại đây: [React Native - Native Modules](https://docs.expo.dev/versions/latest/)

## 2. Sử dụng Camera để chụp ảnh đưa vào ứng dụng (Image Picker)
Trong ứng dụng React Native, khi chúng ta muốn chọn ảnh từ thư viện hoặc chụp ảnh từ Camera, chúng ta có thể sử dụng thư viện `expo-image-picker`.

### 2.1. Cài đặt
Để cài đặt thư viện `expo-image-picker`, chúng ta sử dụng lệnh sau:
```bash
npx expo install expo-image-picker
# hoặc
npm install expo-image-picker
```
Chi tiết về thư viện `expo-image-picker`, xem tại đây: [Expo Image Picker](https://docs.expo.dev/versions/latest/sdk/imagepicker/) 

### 2.2. Sử dụng
#### 2.2.1. Thêm cấu hình vào file `app.json`
Trước khi sử dụng thư viện `expo-image-picker`, chúng ta cần thêm cấu hình sau vào file `app.json` để cho phép ứng dụng truy cập vào Camera và thư viện ảnh của thiết bị (Cần thiết cho `IOS`).

Có 3 định dạng cấu hình:
- Cho phép truy cập vào `Thư viện`: `photosPermission`.
- Cho phép truy cập vào `Camera`: `cameraPermission`.
- Cho phép truy cập vào `Microphone`: `microphonePermission`.

Trong phần này, chúng ta sẽ thêm cấu hình cho việc truy cập vào Camera của thiết bị:
> app.json
```json
{
  "expo": {
    "plugins": [
      [
        "expo-image-picker",
        {
          "cameraPermission": "Custom text for information about photos permission",
        }
      ]
    ]
  }
}
```

#### 2.2.2. Sử dụng thư viện `expo-image-picker`
Chúng ta có các hàm chính sau trong thư viện `expo-image-picker` để sử dụng:
- `launchCameraAsync` <Promise>: Mở Camera để chụp ảnh. Hàm này trả về một Promise chứa thông tin ảnh đã chụp. Bao gồm `{ assets: [{ uri, width, height, type, ... }], cancelled, ... }`. Vì thế có thể sử dụng tag `Image` để hiển thị ảnh với `uri` trả về.
- `launchImageLibraryAsync` <Promise>: Mở thư viện ảnh để chọn ảnh. Hàm này trả về một Promise chứa thông tin ảnh đã chọn.
- `useCameraPermissions` <Function>: Là một hook trả về 2 giá trị: `info` và `ask`.
  + `info` <Object>: Là một Object chứa thông tin về quyền truy cập Camera. (Ví dụ: `status`, `canAskAgain`, `granted`, `expires`, ...)
  + `request` <Promise>: Đây là hàm để yêu cầu quyền truy cập Camera. Nó trả về một Promise là biến `info` chứa thông tin về quyền truy cập Camera. (Ví dụ: `status`, `canAskAgain`, `granted`, `expires`, ...)
- `PermissionStatus` <Object>: Là một Object chứa các trạng thái của quyền truy cập Camera (`GRANTED(đã được cấp quyền)`, `DENIED(đã bị từ chối)`, `UNDETERMINED(chưa xác định)`).
- `PermissionExpiration` <Object>: Là một Object chứa các thời gian hết hạn của quyền truy cập Camera (`NEVER(Chưa bao giờ hết hạn)`, `UNKNOWN(Không xác định)`).
- `MediaTypeOptions` <Object>: Là một Object chứa các loại ảnh (`ALL`, `VIDEO`, `IMAGES`).

> LƯU Ý, ĐỐI VỚI `launchCameraAsync` và `launchImageLibraryAsync`, chúng ta có các `options` để cấu hình cho việc chụp ảnh hoặc chọn ảnh như:
- `allowsEditing` <Boolean>: Cho phép chỉnh sửa ảnh sau khi chụp hoặc chọn.
- `allowsMultipleSelection` <Boolean>: Cho phép chọn nhiều ảnh.
- `aspect` <Array>: Một mảng chứa tỉ lệ ảnh (Ví dụ: `[4, 3]`).
- `base64` <Boolean>: Trả về ảnh dưới dạng base64.
- `quality` <Number>: Chất lượng ảnh (0-1).
- `cameraType` <CameraType>: Loại Camera (`front`, `back`). Mặc định là `CameraType.back`.
- `exif` <Boolean>: Trả về thông tin EXIF của ảnh. Đây là một chuỗi JSON chứa thông tin về ảnh như `DateTime`, `GPS`, `Make`, `Model`, `Orientation`, `Software`, `XResolution`, `YResolution`, ...
- `mediaTypes` <MediaTypeOptions>: Loại ảnh (`imàges`, `video`, `all`). Mặc định là `MediaTypeOptions.Images`.
- `selectionLimit` <Number>: Giới hạn số lượng ảnh được chọn. Nếu `allowsMultipleSelection` là `true`, thì `selectionLimit` phải lớn hơn 1.
- `videoQuality` <UIImagePickerControllerQualityType>: Chất lượng video (`low`, `medium`, `high`, `480p`, `720p`, `1080p`, `2160p`, `4K`, `iFrame960x540`, `iFrame1280x720`).
- `videoMaxDuration` <Number>: Thời gian tối đa của video (giây). Mặc định là `0` (Không giới hạn).

### 2.3. Ví dụ
```jsx
import { View, Text, StyleSheet, Image } from "react-native";
import {
  launchCameraAsync, // Hàm mở camera và chụp ảnh
  useCameraPermissions, // Hook trả về 2 thông tin: status (trạng thái quyền truy cập camera) và request (hàm yêu cầu quyền truy cập camera)
  PermissionStatus, // Hàm chứa thông tin về quyền truy cập camera (có thể là 'granted', 'denied', 'undetermined')
} from "expo-image-picker";
import { useState } from "react";

import { Colors } from "../../constants/colors";
import OutlinedButton from "../UI/OutlinedButton";

function ImagePicker() {
  const [image, setImage] = useState(null); // State chứa ảnh đã chụp
  const [cameraPermission, requestCameraPermission] = useCameraPermissions(); // Lấy thông tin quyền truy cập camera

  async function hasVerifyCameraPermission() {
    if (cameraPermission.status === PermissionStatus.UNDETERMINED) {
      // Nếu quyền truy cập camera chưa được xác định
      const response = await requestCameraPermission(); // Yêu cầu quyền truy cập camera

      return response.granted; // Trả về kết quả xác định quyền truy cập camera (true hoặc false)
    }

    if (cameraPermission.status === PermissionStatus.DENIED) {
      // Nếu quyền truy cập camera bị từ chối
      return false; // Trả về false
    }

    return true; // Ngược lại Trả về true nếu quyền truy cập camera đã được cấp
  }

  async function takeImageHandler() {
    if (!(await hasVerifyCameraPermission())) {
      // Nếu quyền truy cập camera bị từ chối
      return; // Thoát khỏi hàm
    }
    const imagePicker = await launchCameraAsync(); // Mở camera và chụp ảnh
    setImage(imagePicker.assets[0].uri); // Lưu uri ảnh đã chụp vào state image
  }

  let imagePreview = <Text>No image picked yet.</Text>; // Mặc định hiển thị thông báo "No image picked yet."

  if (image) {
    // Nếu đã chụp ảnh
    imagePreview = <Image source={{ uri: image }} style={styles.image} />; // Hiển thị ảnh đã chụp
  }

  return (
    <View>
      <View style={styles.imagePreview}>{imagePreview}</View>
      <OutlinedButton icon="camera" onPress={takeImageHandler}>
        Take Image
      </OutlinedButton>
    </View>
  );
}

export default ImagePicker;

const styles = StyleSheet.create({
  imagePreview: {
    width: "100%",
    height: 200,
    marginVertical: 8,
    justifyContent: "center",
    alignItems: "center",
    backgroundColor: Colors.primary100,
    borderRadius: 4,
  },
  image: {
    width: "100%",
    height: "100%",
  },
});
```

## 3. Sử dụng Location để lấy vị trí
Trong ứng dụng React Native, khi chúng ta muốn lấy vị trí của thiết bị, chúng ta có thể sử dụng thư viện `expo-location`.

Chi tiết về thư viện `expo-location`, xem tại đây: [Expo Location](https://docs.expo.dev/versions/latest/sdk/location/)

### 3.1. Cài đặt
Để cài đặt thư viện `expo-location`, chúng ta sử dụng lệnh sau:
```bash
npx expo install expo-location
# hoặc
npm install expo-location
```

### 3.2. Sử dụng
#### 3.2.1. Thêm cấu hình vào file `app.json`
Trước khi sử dụng thư viện `expo-location`, chúng ta cần thêm cấu hình sau vào file `app.json` để cho phép ứng dụng truy cập vào vị trí của thiết bị.

Có 6 định dạng cấu hình:
- `locationAlwaysAndWhenInUsePermission`: Cho phép truy cập vào vị trí của thiết bị mọi lúc và khi ứng dụng đang sử dụng (IOS).
- `locationAlwaysPermission`: Cho phép truy cập vào vị trí của thiết bị mọi lúc (IOS).
- `locationWhenInUsePermission`: Cho phép truy cập vào vị trí của thiết bị khi ứng dụng đang sử dụng (IOS).
- `isIOSBackgroundLocationEnabled`: Cho phép truy cập vào vị trí của thiết bị khi ứng dụng đang ở nền (IOS). Mặc định là `false`.
- `isAndroidBackgroundLocationEnabled`: Cho phép truy cập vào vị trí của thiết bị khi ứng dụng đang ở nền (Android). Mặc định là `false`.
- `isAndroidForegroundServiceEnabled`: Cho phép truy cập vào vị trí của thiết bị khi ứng dụng đang ở trước cảnh (Android). Mặc định là `false`.

Trong phần này, chúng ta sẽ thêm cấu hình cho việc truy cập vào vị trí của thiết bị:
> app.json
```json
{
  "expo": {
    "plugins": [
      [
        "expo-location",
        {
          "locationAlwaysAndWhenInUsePermission": "Custom text for information about location permission",
        }
      ]
    ]
  }
}
```

#### 3.2.2. Sử dụng thư viện `expo-location`
Chúng ta có các hàm chính sau trong thư viện `expo-location` để sử dụng:
- `getCurrentPositionAsync` <Promise>: Lấy vị trí hiện tại của thiết bị. Hàm này trả về một Promise chứa thông tin vị trí của thiết bị. Bao gồm `{ coords: { latitude, longitude, altitude, accuracy, altitudeAccuracy, heading, speed }, timestamp }`.
- `useForegroundPermissions` <Function>: Là một hook trả về 2 giá trị: `info` và `ask`.
  + `info` <Object>: Là một Object chứa thông tin về quyền truy cập vị trí khi ứng dụng đang ở trước cảnh (Android). (Ví dụ: `status`, `canAskAgain`, `granted`, `expires`, ...)
  + `request` <Promise>: Đây là hàm để yêu cầu quyền truy cập vị trí khi ứng dụng đang ở trước cảnh (Android). Nó trả về một Promise là biến `info` chứa thông tin về quyền truy cập vị trí khi ứng dụng đang ở trước cảnh (Android). (Ví dụ: `status`, `canAskAgain`, `granted`, `expires`, ...)
- `useBackgroundPermissions` <Function>: Là một hook trả về 2 giá trị: `info` và `ask`.
  + `info` <Object>: Là một Object chứa thông tin về quyền truy cập vị trí khi ứng dụng đang ở nền (Android). (Ví dụ: `status`, `canAskAgain`, `granted`, `expires`, ...)
  + `request` <Promise>: Đây là hàm để yêu cầu quyền truy cập vị trí khi ứng dụng đang ở nền (Android). Nó trả về một Promise là biến `info` chứa thông tin về quyền truy cập vị trí khi ứng dụng đang ở nền (Android). (Ví dụ: `status`, `canAskAgain`, `granted`, `expires`, ...)
- `watchPositionAsync` <Promise>: Theo dõi vị trí của thiết bị. Hàm này trả về một Promise chứa thông tin vị trí của thiết bị. Bao gồm `{ coords: { latitude, longitude, altitude, accuracy, altitudeAccuracy, heading, speed }, timestamp }`.
- `getProviderStatusAsync` <Promise>: Lấy trạng thái của dịch vụ vị trí. Hàm này trả về một Promise chứa thông tin trạng thái của dịch vụ vị trí. Bao gồm `{ locationServicesEnabled, gpsAvailable, networkAvailable, passiveAvailable }`.
- `getLastKnownPositionAsync` <Promise>: Lấy vị trí cuối cùng của thiết bị. Hàm này trả về một Promise chứa thông tin vị trí cuối cùng của thiết bị. Bao gồm `{ coords: { latitude, longitude, altitude, accuracy, altitudeAccuracy, heading, speed }, timestamp }`.
- `geocodeAsync` <Promise>: Chuyển đổi vị trí thành địa chỉ. Hàm này trả về một Promise chứa thông tin địa chỉ của vị trí. Bao gồm `{ latitude, longitude, altitude, accuracy, altitudeAccuracy, heading, speed }`.
- `reverseGeocodeAsync` <Promise>: Chuyển đổi địa chỉ thành vị trí. Hàm này trả về một Promise chứa thông tin vị trí của địa chỉ. Bao gồm `{ latitude, longitude, altitude, accuracy, altitudeAccuracy, heading, speed }`.
- `PermissionStatus` <Object>: Là một Object chứa các trạng thái của quyền truy cập vị trí (`GRANTED(đã được cấp quyền)`, `DENIED(đã bị từ chối)`, `UNDETERMINED(chưa xác định)`).

> LƯU Ý, NÊN SỬ DỤNG `useForegroundPermissions` THAY VÌ `useBackgroundPermissions` VÌ `useForegroundPermissions` CHỈ HỎI QUYỀN TRUY CẬP KHI ỨNG DỤNG ĐANG SỬ DỤNG, CÒN `useBackgroundPermissions` SẼ HỎI QUYỀN TRUY CẬP KHI ỨNG DỤNG ĐANG Ở NỀN, SẼ GÂY RA SỰ KHÓ CHỊU CHO NGƯỜI DÙNG.

### 3.3. Ví dụ lấy vị trí hiện tại của thiết bị
```jsx
import { View, StyleSheet } from "react-native";
import {
  getCurrentPositionAsync, // Lấy vị trí hiện tại của thiết bị
  useForegroundPermissions, // Hook trả về status, request quyền truy cập vị trí
  PermissionStatus, // Status của quyền truy cập vị trí
} from "expo-location";

import { Colors } from "../../constants/colors";
import OutlinedButton from "../UI/OutlinedButton";

function LocationPicker() {
  const [permissionStatus, requestPermission] = useForegroundPermissions();

  async function isVerifyPermission() {
    if (permissionStatus !== PermissionStatus.GRANTED) {
      // Nếu chưa được cấp quyền
      const response = await requestPermission(); // Yêu cầu cấp quyền
      return response.status; // Trả về status của quyền truy cập vị trí
    }
    if (permissionStatus === PermissionStatus.DENIED) {
      // Nếu bị từ chối
      return false; // Trả về false
    }
    return true; // Ngược lại trả về true
  }

  async function getLocationHandler() {
    const isPermission = await isVerifyPermission(); // Kiểm tra quyền truy cập vị trí
    if (!isPermission) {
      // Nếu không được cấp quyền
      return; // Thoát
    }
    const location = await getCurrentPositionAsync(); // Lấy vị trí hiện tại của thiết bị
    console.log(location); // Hiển thị thông tin vị trí
  }

  function pickOnMapHandler() {}

  return (
    <View>
      <View style={styles.mapPreview}></View>
      <View style={styles.actions}>
        <OutlinedButton icon="location" onPress={getLocationHandler}>
          Locate User
        </OutlinedButton>
        <OutlinedButton icon="map" onPress={pickOnMapHandler}>
          Pick on Map
        </OutlinedButton>
      </View>
    </View>
  );
}

export default LocationPicker;

const styles = StyleSheet.create({
  mapPreview: {
    width: "100%",
    height: 200,
    marginVertical: 8,
    justifyContent: "center",
    alignItems: "center",
    backgroundColor: Colors.primary100,
    borderRadius: 4,
  },
  actions: {
    flexDirection: "row",
    justifyContent: "space-around",
    alignItems: "center",
  },
});
```
