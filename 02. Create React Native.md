# Tạo 1 dự án React Native mới
## 1. Cài đặt ExpoCLI (Nếu chưa cài đặt)
> Cài đặt ExpoCLI:
```bash
npm install -g expo-cli
```

## 2. Sử dụng ExpoCLI để tạo 1 dự án React Native mới
Ta sử dụng lệnh sau để tạo 1 dự án React Native mới:
- Đối với app `js` (Template Blank):
```bash
npx create-expo-app --template blank my-new-app
```
- Đối với app `typescript` (Template Blank):
```bash
npx create-expo-app --template blank-typescript my-new-app
```
