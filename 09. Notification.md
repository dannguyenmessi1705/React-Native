# Notification trong React-Native
## 1. Giới thiệu
Chúng ta có 2 loại thông báo trong React-Native:
- Local Notification: Thông báo hiển thị trên thiết bị của người dùng. Đây là những `trigger` tạo bởi ứng dụng đã cài đặt trên thiết bị. Các thông báo được lên lịch, phân bổ và xử lý trên cùng một thiết bị (Không có sự tham gia của máy chủ). Ví dụ như `Báo thức`, `Nhắc nhở`, `Thông báo từ ứng dụng`.
- Push Notification: Thông báo hiển thị trên thiết bị của người dùng. Đây là những `trigger` tạo bởi máy chủ. Các thông báo được gửi từ máy chủ đến thiết bị người dùng thông qua `Push Notification Service` (Ví dụ như `Firebase Cloud Messaging`, `OneSignal`, `Expo Notification`). Ví dụ như `user1` gửi tin nhắn cho `user2`, Nội dung thông báo sẽ được gửi từ máy chủ đến thiết bị của `user2`.

Chi tiết hơn về Expo Notification xem tại
- [Expo Local Notification](https://docs.expo.dev/versions/latest/sdk/notifications/)
- [Expo Push Notification](https://docs.expo.dev/push-notifications/push-notifications-setup/)

## 2. Cài đặt `Local Notification` trong React-Native
Nếu không sử dụng `Expo`, chúng ta cần xem tại dây dành cho [Expo Bare Workflow](https://github.com/expo/expo/tree/main/packages/expo-notifications#installation-in-bare-react-native-projects)

### 2.1. Cài đặt thư viện
```bash
npx expo install expo-notifications
// hoặc
npm install expo-notifications
```
### 2.2. Cấu hình file `app.json`
Để sử dụng Notification, chúng ta cần cấu hình file `app.json` như sau:
- `icon`: Đường dẫn đến icon sử dụng cho thông báo. (Chỉ áp dụng cho Android)
- `color`: Màu sắc của icon. (Chỉ áp dụng cho Android)
- `sounds`: Danh sách các file âm thanh sử dụng cho thông báo.
- `defaultChannel`: Tên của channel mặc định.

>app.json
```json
{
  "expo": {
    "plugins": [
      [
        "expo-notifications",
        {
          "icon": "./local/assets/notification-icon.png",
          "color": "#ffffff",
          "defaultChannel": "default",
          "sounds": [
            "./local/assets/notification-sound.wav",
            "./local/assets/notification-sound-other.wav"
          ]
        }
      ]
    ]
  }
}
```

### 2.3. Sử dụng `Expo Notification`
#### 2.3.1. Cấp quyền khi chạy ứng dụng
Trước hết, muốn sử dụng Notification, chúng ta cần cấp quyền cho ứng dụng thông qua hàm `requestPermissionsAsync()`.
- Đối với Android, hàm này sẽ hiện thông báo cấp quyền.
- Đối với IOS, chúng ta cần phải config thêm 1 số thuộc tính.

Sau đó, chúng ta sẽ chạy hàm này mỗi khi component App được `Mount`.

>App.js
```javascript
import * as Notifications from "expo-notifications"; // Import thư viện

// Hàm này mỗi khi chạy nếu chưa cấp quyền sẽ hiện thông báo cấp quyền
async function requestPermissionsForNotification() {
  return await Notifications.requestPermissionsAsync({
    ios: {
      allowAlert: "true", // Cho phép hiện thông báo
      allowBadge: "true", // Cho phép hiện số thông báo
      allowSound: "true", // Cho phép phát âm thanh
      allowAnnouncements: "true" // Cho phép hiện thông báo ở màn hình khóa
    } // IOS Phải cấu hình thêm ở đây
  }) // Hàm này mỗi khi chạy nếu chưa cấp quyền sẽ hiện thông báo cấp quyền, mặc định Android khi chạy hàm này sẽ hiện thông báo cấp quyền
} 
// ...
function App() {
  // ...
  useEffect(() => {
    requestPermissionsForNotification();
  }, []); // Hàm này sẽ chạy khi mở ứng dụng, dùng để cấp quyền
}
```

#### 2.3.2. Cài đặt `channel` kênh thông báo (CHỈ DÀNH CHO ANDROID >= 8) MẶC ĐỊNH KHÔNG CẦN THIẾT ĐỐI VỚI IOS
Để hiển thị thông báo trên Android >= 8, chúng ta cần phải tạo `channel` thông báo. Mỗi `channel` sẽ có 1 `id` riêng biệt.

Chúng ta sẽ tạo `channel` thông báo thông qua hàm `setNotificationChannelAsync()`. Hàm này sẽ tạo `channel` thông báo với các thuộc tính như `name`, `importance`, `enableVibrate`, `vibrationPattern`, `lightColor`, `lockscreenVisibility`, `sound`.

Sau đó, chúng ta sẽ chạy hàm này mỗi khi component App được `Mount`. Và khi lập lịch thông báo, chúng ta sẽ set trigger với `channelId` là `id` của `channel` thông báo.

>App.js
```javascript
import * as Notifications from "expo-notifications"; // Import thư viện

// Hàm này sẽ tạo channel cho Android >= 8 để hiện thông báo, có có thể có nhiều channel (Android >= 8)
async function setNotificationChannel() {
  await Notifications.setNotificationChannelAsync("test", {
    name: "Notification Channel", // Tên channel
    importance: Notifications.AndroidImportance.HIGH, // Mức độ quan trọng
    enableVibrate: true, // Cho phép rung
    vibrationPattern: [0, 250, 250, 250], // Chuỗi rung [delay, rung, delay, rung, ...]
    lightColor: "#FF231F7C", // Màu sáng khi có thông báo
    lockscreenVisibility: Notifications.AndroidNotificationVisibility.PUBLIC, // Hiển thị thông báo ở màn hình khóa
    // sound: "notification.wav" // Âm thanh thông báo (KHÔNG NÊN SỬ DỤNG)
  }) // Chỉ dành cho Android
} 

function App () {
  // ...
  useEffect(() => {
    setNotificationChannel();
  }, []); // Hàm này sẽ chạy khi mở ứng dụng, dùng để cấp quyền và tạo channel
  
  // Set trigger với channelId là id của channel (Thực hiện ở phần lên lịch thông báo (#### 2.3.3))
}
```

#### 2.3.3. Lên lịch thông báo (Set trigger)
Để lên lịch thông báo, chúng ta sẽ sử dụng hàm `scheduleNotificationAsync()`. Hàm này sẽ lên lịch thông báo với các thuộc tính như `content`, `trigger`.
- `content`: Là nội dung thông báo với các thuộc tính như `title`, `body`, `sound`.
- `trigger`: Là trigger để thông báo được hiển thị với các thuộc tính như `seconds`, `channelId`.
- `channelId`: Là `id` của `channel` thông báo (Nếu không có `channel` thông báo, không cần thiết).

Hàm này sẽ được gọi khi người dùng thực hiện 1 hành động nào đó, ví dụ như click vào 1 button.

>App.js
```javascript
import * as Notifications from "expo-notifications"; // Import thư viện
// SET QUYỀN, TẠO CHANNEL Ở ĐÂY

function App() {
  // ...
  async function handleButtonClickReceiveNotification() {
    await Notifications.scheduleNotificationAsync({ // Hàm này sẽ lên lịch hiện thông báo sau khi trigger bật lên
      content: {
        title: "Local Notification", // Tiêu đề thông báo
        body: "This is a local notification", // Nội dung thông báo
        // sound: "notification.wav" // Chỉ dành cho Android <= 8 (KHÔNG NÊN SỬ DỤNG)
      },
      trigger: {
        seconds: 2, // Thời gian sau bao lâu sẽ hiện thông báo sau khi trigger bật lên 
        channelId: "test", // Chỉ dành cho Android >= 8 (Chọn channel để hiện thông báo)
      }
    })
  }

  return (
    <View style={styles.container}>
      <Text>Open up App.js to start working on your app!</Text>
      <Button title="Click to receive notification" onPress={() => handleButtonClickReceiveNotification()}/>
      <StatusBar style="auto" />
    </View>
  );
}
```

#### 2.3.4. Xử lý khi có thông báo.
Để xử lý khi có thông báo, chúng ta sẽ sử dụng hàm `setNotificationHandler()`. Hàm này sẽ xử lý thông báo khi thông báo đến với các thuộc tính như:
- `handleNotification`: Là hàm xử lý thông báo với các thuộc tính như `shouldShowAlert`, `shouldPlaySound`, `shouldSetBadge`.
    + `shouldShowAlert`: Hiện thông báo.
    + `shouldPlaySound`: Phát âm thanh.
    + `shouldSetBadge`: Hiện số thông báo.
- `handleSuccess`: Là hàm xử lý khi thông báo được xử lý thành công.
- `handleError`: Là hàm xử lý khi thông báo xử lý thất bại.

Hàm này mặc định sẽ được gọi luôn trong suốt quá trình chạy ứng dụng. Nên chúng ta cần thiết lập hàm ở bên ngoài component App.

>App.js
```javascript
import * as Notifications from "expo-notifications"; // Import thư viện
// SET QUYỀN, TẠO CHANNEL Ở ĐÂY

Notifications.setNotificationHandler({
  handleNotification: async (notify) => {
    return {
      shouldShowAlert: true, // Hiện thông báo
      shouldPlaySound: true, // Phát âm thanh
      shouldSetBadge: true // Hiện số thông báo
    }
  }
}); // Hàm này sẽ xử lý thông báo khi thông báo đến

function App() {
  // ...
}
```

#### 2.3.5. Xử lý, tương tác với nội dung thông báo khi có thông báo
Để xử lý, tương tác với nội dung thông báo khi có thông báo, chúng ta sẽ sử dụng hàm `addNotificationReceivedListener()`. Hàm này sẽ lắng nghe mỗi khi có thông báo đến với các thuộc tính như:
- `date`: Thời gian thông báo đến.
- `request`: Thông tin thông báo.
    + `content`: Nội dung thông báo với các thuộc tính như `title`, `body`, `sound`.
    + `trigger`: Trigger thông báo với các thuộc tính như `seconds`, `channelId`.
    + `identifier`: `id` của thông báo.

Chúng ta sử dụng bằng cách gọi hàm `addNotificationReceivedListener()` mỗi khi component App được `Mount`. Và `remove()` mỗi khi component App bị `Unmount`.

Sử dụng việc này với mục đích xử lý thông báo khi thông báo đến. Ứng dụng cho các trường hợp như `Chuyển màn hình khi click vào thông báo`, `Xử lý thông báo khi thông báo đến`.

>App.js
```javascript
import * as Notifications from "expo-notifications"; // Import thư viện
// SET QUYỀN, TẠO CHANNEL Ở ĐÂY
// HANDLE NOTIFICATION Ở ĐÂY

function App() {
  // ...
  useEffect(() => {
    const subscription = Notifications.addNotificationReceivedListener((notify) => {
      console.log(notify);
    }); // Hàm này sẽ lắng nghe mỗi khi có thông báo đến

    return () => subscription.remove(); // Hàm này sẽ remove khi component App bị Unmount
  }, []);
}
```

#### 2.3.6. Xử lý, tương tác với thông báo khi người dùng click vào thông báo
Để xử lý, tương tác với thông báo khi người dùng click vào thông báo, chúng ta sẽ sử dụng hàm `addNotificationResponseReceivedListener()`. Hàm này sẽ lắng nghe mỗi khi người dùng click vào thông báo với các thuộc tính như:
- `actionIdentifier`: `id` của hành động. Mặc định có 2 hành động là `default` và `dismissed`.
- `notification`: Thông tin thông báo với các thuộc tính như `request` của hàm `addNotificationReceivedListener()`.

Chúng ta sử dụng bằng cách gọi hàm `addNotificationResponseReceivedListener()` mỗi khi component App được `Mount`. Và `remove()` mỗi khi component App bị `Unmount`.

Sử dụng việc này với mục đích xử lý thông báo khi người dùng click vào thông báo. Ứng dụng cho các trường hợp như `Xác định có chính xác người dùng đã click vào thông báo`, `Chuyển màn hình khi click vào thông báo`.

>App.js
```javascript
import * as Notifications from "expo-notifications"; // Import thư viện
// SET QUYỀN, TẠO CHANNEL Ở ĐÂY
// HANDLE NOTIFICATION Ở ĐÂY

function App() {
  // ...
  useEffect(() => {
    const subscription = Notifications.addNotificationResponseReceivedListener((notify) => {
      console.log(notify);
    }); // Hàm này sẽ lắng nghe mỗi khi người dùng click vào thông báo

    return () => subscription.remove(); // Hàm này sẽ remove khi component App bị Unmount
  }, []);
}
```

## 3. Cài đặt `Push Notification` trong React-Native (Sử dụng `Expo Notification`)
Chúng ta sẽ sử dụng các module sau:
- `expo-notifications`: Để xử lý thông báo.
- `expo-constants`: Để lấy giá trị `projectId` từ cấu app config.
- `expo-device`: Để kiểm tra xem ứng dụng có đang chạy trên thiết bị vật lý hay không.

```bash
npx expo install expo-notifications expo-device expo-constants
## hoặc
npm install expo-notifications expo-device expo-constants
```

### 3.1. Cấu hình `Push Notification` trong `Expo Notification` sử dụng `Expo Push Notification Service`
#### 3.1.1. Tạo `projectId` cho ứng dụng
Để cấu hình `Push Notification` trong `Expo Notification`, chúng ta cần phải có `projectId` từ cấu hình app. Để tạo `projectId`, chúng ta cần thực hiện lệnh sau để build `eas.json`:
```bash
npx eas build:configure
```

#### 3.1.2. Cấu hình `Push Notification` trong `App.js`
Chúng ta sẽ cấu hình `Push Notification` trong `App.js` như sau:
- Tạo hàm `registerForPushNotificationsAsync() <Promise>` gồm các nhiệm vụ như `Lấy quyền`, `Tạo Channel (nếu là Android)`, `đăng ký Push Notification Token` với `projectId` đã cấu hình. Nếu đăng ký thành công, sẽ trả về `token` của thiết bị. Nếu không, sẽ trả về thông báo lỗi.
- Sử dụng `useEffect` để chạy hàm cấu hình `Push Notification` mỗi khi component App được `Mount`.
- Token sẽ có dạng: `ExponentPushToken[token_id]`
>App.js
```javascript
import * as Notifications from "expo-notifications";
import * as Device from "expo-device"
import Constants from "expo-constants";
import { useEffect } from "react"

// XỬ LÝ THÔNG BÁO ĐẾN
Notifications.setNotificationHandler({
  handleNotification: async (notify) => {
    return {
      shouldShowAlert: true, // Hiện thông báo
      shouldPlaySound: true, // Phát âm thanh
      shouldSetBadge: true // Hiện số thông báo
    }
  }
}); // Hàm này sẽ xử lý thông báo khi thông báo đến

// HÀM CẤU HÌNH NOTIFICATION (QUYỀN, CHANNEL, ĐĂNG KÝ TOKEN PUSH NOTIFICATION)
function handleRegistrationError(errorMessage) {
  alert(errorMessage);
  throw new Error(errorMessage);
}

// Tạo hàm để đăng ký thông báo từ server (push notification) (Bao gồm cấp quyền, tạo channel, lấy token)
async function registerForPushNotificationsAsync() {
  if (Platform.OS === 'android') { // Nếu là Android thì tạo channel
    await Notifications.setNotificationChannelAsync("test", {
      name: "Notification Channel", // Tên channel
      importance: Notifications.AndroidImportance.HIGH, // Mức độ quan trọng
      enableVibrate: true, // Cho phép rung
      vibrationPattern: [0, 250, 250, 250], // Chuỗi rung [delay, rung, delay, rung, ...]
      lightColor: "#FF231F7C", // Màu sáng khi có thông báo
      lockscreenVisibility: Notifications.AndroidNotificationVisibility.PUBLIC, // Hiển thị thông báo ở màn hình khóa
      // sound: "notification.wav" // Âm thanh thông báo (KHÔNG NÊN SỬ DỤNG)
    }) // Chỉ dành cho Android >= 8 (Tạo channel để hiện thông báo)
  }

  if (Device.isDevice) { // Nếu là thiết bị thật thì mới lấy token (Không lấy trên máy ảo)
    const { status: existingStatus } = await Notifications.getPermissionsAsync(); // Lấy quyền thông báo, nếu chưa có sẽ hiện thông báo cấp quyền
    let finalStatus = existingStatus; // Đặt biến finalStatus bằng existingStatus
    if (existingStatus !== 'granted') { // Nếu chưa cấp quyền (Do lần đầu cài đặt)
      const { status } = await Notifications.requestPermissionsAsync({
        ios: {
          allowAlert: "true", // Cho phép hiện thông báo
          allowBadge: "true", // Cho phép hiện số thông báo
          allowSound: "true", // Cho phép phát âm thanh
          allowAnnouncements: "true" // Cho phép hiện thông báo ở màn hình khóa
        } // IOS Phải cấu hình thêm ở đây
      }); // Yêu cầu cấp quyền
      finalStatus = status; // Đặt biến finalStatus bằng status
    }
    if (finalStatus !== 'granted') { // Nếu trạng thái cuối cùng không được cấp quyền (Do người dùng không cấp quyền)
      handleRegistrationError('Permission not granted to get push token for push notification!'); // Thông báo lỗi
      return; // Kết thúc hàm
    }
    const projectId =
            Constants?.expoConfig?.extra?.eas?.projectId ?? Constants?.easConfig?.projectId; // Lấy projectId từ Constants
    if (!projectId) {
      handleRegistrationError('Project ID not found'); // Thông báo lỗi nếu không tìm thấy projectId
    }
    try {
      const pushTokenString = (
              await Notifications.getExpoPushTokenAsync({
                projectId,
              })
      ).data; // Lấy token từ server (push notification)
      console.log(pushTokenString); // Log token
      return pushTokenString; // Trả về token
    } catch (e) {
      handleRegistrationError(`${e}`); // Thông báo lỗi nếu có lỗi
    }
  } else { // Nếu không phải thiết bị thật
    handleRegistrationError('Must use physical device for push notifications'); // Thông báo lỗi
  }
}
```

#### 3.1.3. Gửi thông báo từ máy chủ đến thiết bị
Chúng ta cài đặt, code `Backend` để gửi thông báo từ máy chủ đến thiết bị thông qua `Expo Push Notification Service`.

`Expo Push Notification Service` cung cấp 1 API để gửi thông báo từ máy chủ đến thiết bị. Có rất nhiều `SDK` hỗ trợ như `NodeJS`, `Python`, `PHP`, `Java`, `Go`, `Ruby`, `C#`, `Curl`. Chi tiết tham khảo tại: [Send notifications with Expo's Push API](https://docs.expo.dev/push-notifications/sending-notifications/)

Ngoài ra, chúng ta có thể test thông báo thông qua `Expo Notification Tool` tại: [Expo Notification Tool](https://expo.dev/notifications). Sau đó chúng ta sẽ nhập `token` đã lấy từ thiết bị vào và gửi thông báo.

Hoặc sử dụng Curl để gửi thông báo:
```bash
curl -H "Content-Type: application/json" -X POST "https://exp.host/--/api/v2/push/send" -d '{
  "to": "ExponentPushToken[xxxxxxxxxxxxxxxxxxxxxx]",
  "title":"hello",
  "body": "world"
}'
```
