# Navigation trong React Native
## 1. Giới thiệu
`Navigation` là một phần quan trọng trong mọi ứng dụng di động, giúp người dùng dễ dàng di chuyển giữa các màn hình khác nhau. Trong React Native, chúng ta có nhiều thư viện hỗ trợ việc quản lý `Navigation`, trong đó có `React Navigation`.

Xem thêm tài liệu hướng dẫn tại đây: [React Navigation](https://reactnavigation.org/docs/getting-started/)

## 2. Cài đặt React Navigation
Để cài đặt `React Navigation`, chúng ta sử dụng lệnh sau:
```bash
npm install @react-navigation/native
```

Tiếp theo, chúng ta cần cài thêm các thư viện sau, mặc định khi sử dụng `React Navigation` thì `Safe Area` sẽ được tự động thiết lập mà không cần tuỳ chỉnh thêm bằng tay.
> Nếu sử dụng `Expo`:
```bash
npx expo install react-native-screens react-native-safe-area-context
```
> Nếu sử dụng `React Native CLI`, chúng ta có lệnh chạy sau:
```bash
npm install react-native-screens react-native-safe-area-context
```

> NGOÀI RA `REACT NATIVE` CẦN CÓ CÁC THƯ VIỆN ĐỂ HỖ TRỢ `REACT NAVIGATION` THEO CÁC CƠ CHẾ NHƯ: `STACK`, `NATIVE STACK`, `DRAWER`, `BOTTOM TAB`, `MATERIAL TOP TAB`, `MATERIAL BOTTOM TAB`. CHI TIẾT HƯỚNG DẪN CÀI ĐẶT CÁC THƯ VIỆN NÀY Ở PHẦN SAU.

## 3. Kích hoạt Navigation trong ứng dụng
Sau khi cài đặt thư viện `@react-navigation/native`, chúng ta cần kích hoạt `Navigation` trong ứng dụng bằng cách `import` component `NavigationContainer` từ thư viện `@react-navigation/native` và bọc toàn bộ ứng dụng bên trong `NavigationContainer` trong file `App.js`:
> App.js
```js
...
import { NavigationContainer } from '@react-navigation/native';

export default function App() {
  return (
    <NavigationContainer>
      ... // Logic, Component khác của ứng dụng
    </NavigationContainer>
  );
}
```
> LƯU Ý: Khi sử dụng `Navigation`, Các style của ứng dụng như `backgroundColor`, `flex`, `justifyContent`, `alignItems` sẽ không còn có hiệu lực. Thay vào đó, chúng ta cần sử dụng các `tùy chọn` của `Navigation` để thiết lập style cho ứng dụng.

## 4. Sử dụng `Native-Stack Navigator` để điều hướng giữa các màn hình
`Stack Navigator` là một trong những cơ chế điều hướng phổ biến nhất trong `React Navigation`, cho phép chúng ta di chuyển giữa các màn hình theo cơ chế `Stack` (ngăn xếp).

### 4.1. Cài đặt `Native-Stack Navigator`
Để cài đặt `Native-Stack Navigator`, chúng ta sử dụng lệnh sau:
```bash
npm install @react-navigation/native-stack
```

### 4.2. Sử dụng `Native-Stack Navigator`
Để sử dụng `Native-Stack Navigator`, chúng ta cần `import` component `createNativeStackNavigator` từ thư viện `@react-navigation/native-stack` và tạo một `Stack Navigator` component mới từ `createNativeStackNavigator` trong file `App.js`:
> App.js
```js
...
import { createNativeStackNavigator } from '@react-navigation/native-stack';
const Stack = createNativeStackNavigator();
```

`Stack` Component được tạo ra từ `createNativeStackNavigator` chứa 2 component con là:
- `Stack.Navigator`: Component cha chứa các màn hình con. Nó có các `thuộc tính` phổ biến sau:
    + `initialRouteName`: Điền `Tên` của màn hình mặc định khi ứng dụng khởi chạy. (Stack.Screen đầu tiên sẽ là màn hình mặc định).
    + `screenOptions`: Chứa 1 object các `tùy chọn` cho các màn hình con. Như: `headerStyle`, `headerTintColor`, `contentStyle`.
- `Stack.Screen`: Component con chứa màn hình con. Có các thuộc tính phổ biến sau:
    + `name`: Tên của màn hình.
    + `component`: Component hiển thị của màn hình.
    + `options`: Chứa 1 object các `tùy chọn` cho màn hình. Như: `headerTitle`, `headerShown`, `headerStyle`, `headerTintColor`, `title`.
> VD:
```js
<NavigationContainer>
        <Stack.Navigator
          initialRouteName="Categories" // Màn hình mặc định khi ứng dụng khởi chạy
          screenOptions={{
            headerStyle: { // Style cho header
              backgroundColor: "#351401", // Màu nền header
            },
            headerTintColor: "white", // Màu chữ header
            contentStyle: { // Style cho nội dung màn hình
              backgroundColor: "#3f2f25",
            },
          }}
        >
          <Stack.Screen
            name="Categories" // Tên của màn hình
            component={CategoryScreen} // Component của màn hình
            options={{
              title: "Meal Categories", // Tiêu đề của màn hình
            }}
          />
          <Stack.Screen
            name="MealsOverview" // Tên của màn hình
            component={MealsOverviewScreen} // Component của màn hình
            options={{
              title: "Meals Overview", // Tiêu đề của màn hình
            }}
          />
        </Stack.Navigator>
      </NavigationContainer>
```

#### 4.2.1. Đăng ký màn hình vào `Stack Navigator` để sử dụng
Để có các `màn hình` phục vụ cho việc điều hướng, chúng ta cần tạo các `màn hình` và đăng ký vào `Stack Navigator` để sử dụng bằng cách thêm các component `Stack.Screen` vào `Stack.Navigator`:

> LƯU Ý: Component `Stack.Screen` đầu tiên trong `Stack.Navigator` sẽ là màn hình mặc định khi ứng dụng khởi chạy. Hoặc có thể sử dụng `initialRouteName` với tên `Stack.Screen` trong `Stack.Navigator` để thiết lập màn hình mặc định.

> Ví dụ: Tạo màn hình `CategoryScreen`, `MealsOverviewScreen` và đăng ký vào `Stack.Navigator`:
```js
...
import { createNativeStackNavigator } from '@react-navigation/native-stack';
const Stack = createNativeStackNavigator();

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator>
        {/* Đăng ký màn hình CategoryScreen vào Stack Navigator */}
        <Stack.Screen name="Category" component={CategoryScreen} /> 
        <Stack.Screen name="MealsOverview" component={MealsOverviewScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}
```

#### 4.2.2. Điều hướng giữa các màn hình sử dụng props `navigation` trong component
Để điều hướng giữa các màn hình, chúng ta sử dụng props `navigation` được truyền vào component để gọi các phương thức điều hướng như `navigate`, `push`, `pop`, `goBack`, `replace`, `reset`:
- `navigate("name", {data})`: Điều hướng đến màn hình khác với `name` là tên của màn hình, `data` là dữ liệu cần truyền vào màn hình đó.
- `push("name", {data})`: Điều hướng đến màn hình khác với `name` là tên của màn hình, `data` là dữ liệu cần truyền vào màn hình đó, tương tự như `navigate`.
- `pop()`: Quay lại màn hình trước đó.
- `goBack()`: Quay lại màn hình trước đó.
- `replace`: Thay thế màn hình hiện tại bằng màn hình khác. Và xóa màn hình hiện tại khỏi `Stack`. (Không thể quay lại và không có nút `Back` để quay lại màn hình trước đó).

> LƯU Ý: PROPS `navigation` CHỈ ĐƯỢC TRUYỀN VÀO CÁC COMPONENT ĐƯỢC ĐĂNG KÝ TRONG `Stack.Screen` thuộc `Stack.Navigator`. NẾU CẦN SỬ DỤNG `navigation` TRONG CÁC COMPONENT KHÁC, CẦN SỬ DỤNG `useNavigation` HOOK ĐỂ LẤY `navigation`.

##### 4.2.2.1. Sử dụng props `navigation` trong component đăng ký trong `Stack.Screen`
> Điều hướng từ `CategoryScreen` sang `MealsOverviewScreen`:Categories
```js
import React from 'react';
import { View, Text, Button } from 'react-native';

const CategoryScreen = ({ navigation }) => {
  return (
    <View>
      <Text>Category Screen</Text>
      <Button title="Go to Meals Overview" onPress={() => navigation.navigate('MealsOverview')} /> 
      {/* `MealsOverview` chính là `name` đã đăng ký ở `Stack.Screen` trong `App.js` */}
    </View>
  );
};
```
##### 4.2.2.2. Sử dụng `useNavigation` Hook trong component không đăng ký trong `Stack.Screen`
> Điều hướng từ `MealsOverviewScreen` sang `CategoryScreen`:
```js
import React from 'react';
import { View, Text, Button } from 'react-native';
import { useNavigation } from '@react-navigation/native';

const MealsOverviewScreen = () => {
  const navigation = useNavigation(); // Lấy `navigation` từ `useNavigation` Hook
  return (
    <View>
      <Text>Meals Overview Screen</Text>
      <Button title="Go to Category" onPress={() => navigation.navigate('Category')} />
    </View>
  );
};
```

> Với `native-stack Navigator` Khi điều hướng đến màn hình khác, trên header sẽ tự động hiển thị nút `Back` để quay lại màn hình trước đó.

#### 4.2.3. Truyền tham số giữa các màn hình, và sử dụng `route` trong component để đọc tham số
Để truyền tham số giữa các màn hình, chúng ta sử dụng `navigation` với tham số thứ 2 là một object chứa các tham số cần truyền. Tương tự có 2 cách sử dụng `navigation`:
- Sử dụng props `navigation` trong component đăng ký trong `Stack.Screen`.
- Sử dụng `useNavigation` Hook trong component không đăng ký trong `Stack.Screen`.
> Ví dụ: Truyền tham số `categoryId` từ `CategoryScreen` sang `MealsOverviewScreen`:
```js
import React from 'react';
import { View, Text, Button } from 'react-native';

const CategoryScreen = ({ navigation }) => {
  return (
    <View>
      <Text>Category Screen</Text>
      <Button title="Go to Meals Overview" onPress={() => navigation.navigate('MealsOverview', { categoryId: 'c1' })} />
    </View>
  );
};
```

Sau đó trong component đích, chúng ta sử dụng `route` để đọc tham số được truyền vào. `route` có các thuộc tính sau:
- `params`: Object chứa các tham số được truyền vào.
- `name`: Tên của màn hình.
- `key`: Key của màn hình.
- `path`: Đường dẫn của màn hình.

Có 2 cách sử dụng `route`:
- Sử dụng props `route` trong component đăng ký trong `Stack.Screen`.
- Sử dụng `useRoute` Hook trong component không đăng ký trong `Stack.Screen`.

> Ví dụ: Đọc tham số `categoryId` từ `CategoryScreen` trong `MealsOverviewScreen`:
```js
import React from 'react';
import { View, Text } from 'react-native';

const MealsOverviewScreen = ({ route }) => {
  const { categoryId } = route.params;
  return (
    <View>
      <Text>Meals Overview Screen</Text>
      <Text>Category ID: {categoryId}</Text>
    </View>
    );
};
```

### 4.2.4. Sử dụng `useIsFocused` Hook để kiểm tra màn hình có được focus hay không
`useIsFocused` Hook được sử dụng để kiểm tra xem hiện tại `Màn hình` có được `Focus` hay không. Hook này trả về `true` nếu màn hình đang được focus, ngược lại trả về `false`.

Mục đích sử dụng `useIsFocused` là để thực hiện các hành động cần thiết như `fetch data`, `update data`, `re-render component`,...

Trong `Stack.Navigator`, khi màn hình đã được hiển thị trước đó và chúng ta quay lại màn hình đó, màn hình sẽ không được `re-render` mặc dù đã thay đổi dữ liệu. Để giải quyết vấn đề này, chúng ta sử dụng `useIsFocused` để kiểm tra màn hình có được focus hay không, nếu có thì thực hiện các hành động cần thiết.

> NÊN SỬ DỤNG `useIsFocused` ĐI VỚI `useEffect` ĐỂ THỰC HIỆN CÁC HÀNH ĐỘNG CẦN THIẾT KHI MÀN HÌNH ĐƯỢC FOCUS.

> Ví dụ: Sử dụng `useIsFocused` Hook trong `MealsOverviewScreen`:
```js
import React, { useEffect } from 'react';
import { View, Text } from 'react-native';
import { useIsFocused } from '@react-navigation/native';

const MealsOverviewScreen = ({ route }) => {
  const isFocused = useIsFocused();
  useEffect(() => {
    if (isFocused) {
      // Thực hiện các hành động cần thiết khi màn hình được focus
    }
  }, [isFocused]);
  return (
    <View>
      <Text>Meals Overview Screen</Text>
      <Text>Category ID: {categoryId}</Text>
      {isFocused && <Text>Screen is focused</Text>}
    </View>
    );
};
```

### 4.2.5. Thiết lập các thông số động (Dynamic) cho các màn hình
Chúng ta có thể thiết lập các thông số động cho các màn hình như `headerTitle`, `headerShown`, `headerStyle`, `headerTintColor`, `title` bằng 2 cách sau:
- Sử dụng `options` trong `Stack.Screen` để thiết lập thông số động cho màn hình.
- Sử dụng `navigation.setOptions` để thiết lập thông số động cho màn hình trong `component`.

#### 4.2.5.1. Sử dụng `options` trong `Stack.Screen` để thiết lập thông số động cho màn hình
Để thiết lập thông số động cho màn hình, chúng ta sử dụng `options` trong `Stack.Screen` với đầu vào là một function chứa object có 2 thuộc tính là `route` và `navigation`, sau đó function trả về `object` chứa các thông số động cần thiết như `headerTitle`, `headerShown`, `headerStyle`, `headerTintColor`, `title`, `headerShown` (ẩn hiện header).

> Ví dụ: Thiết lập `title` động cho `MealsOverviewScreen` ở `App.js`:
```js
...
<Stack.Screen
  name="MealsOverview"
  component={MealsOverviewScreen}
  options={({ route, navigate }) => { 
    const categoryId = route.params.categoryId;
    return {
      title: categoryId,
    };
    }}
/>
```

#### 4.2.5.2. Sử dụng `navigation.setOptions` để thiết lập thông số động cho màn hình trong `component`
Thường sử dụng cách này, chúng ta sẽ thiết lập thông số động cho màn hình trong `component` bằng cách sử dụng `navigation.setOptions` với đầu vào là một object chứa các thông số động cần thiết như `headerTitle`, `headerShown`, `headerStyle`, `headerTintColor`, `title`.

Ngoài ra, khi sử dụng `navigation.setOptions`, chúng ta cần sử dụng `useLayoutEffect` Hook để thiết lập thông số động cho màn hình ngay sau khi màn hình được render.

> Nên sử dụng `useLayoutEffect` thay vì `useEffect` để tránh hiện tượng `Flash`, thay đổi chậm một thành phần nào đó khi màn hình được render. `useLayoutEffect` sẽ chạy ngay sau khi màn hình được render, trước khi người dùng nhìn thấy màn hình.

> Ví dụ: Thiết lập `title` động cho `MealsOverviewScreen` trong `MealsOverviewScreen.js`:
```js
import React, { useLayoutEffect } from 'react';
...
const MealsOverviewScreen = ({ route, navigation }) => {
    useLayoutEffect(() => {
      const { categoryId } = route.params;
        navigation.setOptions({
            title: categoryId,
            contentStyle: {
                backgroundColor: categoryId === 'c1' ? '#3f2f25' : '#351401',
            },
        });
    }, [navigation, categoryId]);
  ...
};
```
### 4.2.6. Thêm `Button` trên `Header` của màn hình
Để thêm `Button` trên `Header` của màn hình, chúng ta sử dụng `options` trong `Stack.Screen` để thiết lập `headerRight` hoặc `headerLeft` với đầu vào là một function chứa object có 2 thuộc tính là `route` và `navigation`, sau đó function trả về `React Element` chứa `Button` cần thêm.

> Ví dụ: Thêm `Button` `Header` cho `MealsOverviewScreen`:
```js
...
<Stack.Screen
  name="MealsOverview"
  component={MealsOverviewScreen}
  options={({ route, navigation }) => {
    return {
      headerRight: () => (
        <Button title="Save" onPress={() => {}} />
      ),
    };
  }}
/>
```

Ngoài ra chúng ta cũng có thể sử dụng `navigation.setOptions` trong `component` để thiết lập `headerRight` hoặc `headerLeft` cho màn hình. Lưu ý, nên đặt `navigation.setOptions` trong `useLayoutEffect` thay vì `useEffect` để tránh hiện tượng `Flash`.

> Ví dụ: Thêm `Button` `Header` cho `MealsOverviewScreen` trong `MealsOverviewScreen.js`:
```js
import React, { useLayoutEffect } from 'react';
...

const MealsOverviewScreen = ({ route, navigation }) => {
  useLayoutEffect(() => {
    navigation.setOptions({
      headerRight: () => (
        <Button title="Save" onPress={() => {}} />
      ),
    });
  }, [navigation]);
  ...
};
```

> LƯU Ý: CẦN PHẢI KÍCH HOẠT `Navigation` TRONG ỨNG DỤNG TRƯỚC KHI SỬ DỤNG `STACK NAVIGATOR`. BẰNG CÁCH BỌC TOÀN BỘ ỨNG DỤNG BÊN TRONG `NavigationContainer`.

## 5. Sử dụng `Drawer Navigator` để hiển thị `Drawer Menu`
`Drawer Navigator` là một trong những cơ chế điều hướng phổ biến nhất trong `React Navigation`, cho phép chúng ta hiển thị `Drawer Menu` bên trái hoặc bên phải của ứng dụng.

`Drawer Navigator` sẽ tự tạo ra `Drawer Menu` khi chúng ta đăng ký các `màn hình` vào `Drawer Navigator`.

### 5.1. Cài đặt `Drawer Navigator`
Để cài đặt `Drawer Navigator`, chúng ta sử dụng lệnh sau:
```bash
npm install @react-navigation/drawer
```

Sau đó, cài thêm các thư viện sau để hỗ trợ thao tác tay như trượt để mở `Drawer Menu`:
```bash
npm install react-native-gesture-handler react-native-reanimated
```

> LƯU Ý: XỬ LÝ LỖI APP KHI CÀI `react-native-reanimated`. NẾU GẶP LỖI, CHÚNG TA CẦN THỰC HIỆN CÁC BƯỚC SAU:
1. Cài đặt `react-native-reanimated` bản mới nhất:
```bash
npm install react-native-reanimated@latest
```
2. Trong file `babel.config.js`, thêm `react-native-reanimated/plugin` vào `plugins`, nếu có các thành phần khác thì cần đặt `react-native-reanimated/plugin` ở cuối cùng:
```js
module.exports = function (api) {
  api.cache(true);
  return {
    presets: ["babel-preset-expo"],
    plugins: ["react-native-reanimated/plugin"], // Thêm dòng này
  };
};
```
3. Chạy lệnh sau để xóa cache:
```bash
npx expo start --clear
```

### 5.2. Sử dụng `Drawer Navigator`
Sử dụng `Drawer Navigator` tương tự như `Stack Navigator`, chúng ta cũng cần `import` component `createDrawerNavigator` từ thư viện `@react-navigation/drawer` và tạo một `Drawer Navigator` component mới từ `createDrawerNavigator` trong file `App.js`:
> App.js
```js
...
import { createDrawerNavigator } from '@react-navigation/drawer';
const Drawer = createDrawerNavigator();
```

`Drawer` Component được tạo ra từ `createDrawerNavigator` chứa 2 component con là:
- `Drawer.Navigator`: Component cha chứa các màn hình con. Nó có các `thuộc tính` phổ biến sau:
    + `initialRouteName`: Điền `Tên` của màn hình mặc định khi ứng dụng khởi chạy. (Drawer.Screen đầu tiên sẽ là màn hình mặc định).
    + `screenOptions`: Chứa 1 object các `tùy chọn` cho các màn hình con. Như: `headerStyle`, `headerTintColor`, `contentStyle`.
- `Drawer.Screen`: Component con chứa màn hình con. Có các thuộc tính phổ biến sau:
    + `name`: Tên của màn hình.
    + `component`: Component hiển thị của màn hình.
    + `options`: Chứa 1 object các `tùy chọn` cho màn hình. Như: `headerTitle`, `headerShown`, `headerStyle`, `headerTintColor`, `title`, `drawerLabel`, `drawerIcon`.

Tất cả quy tắc sử dụng `Drawer Navigator` tương tự như `Stack Navigator`, chỉ khác là `Drawer Navigator` sẽ hiển thị `Drawer Menu` bên trái hoặc bên phải của ứng dụng.

### 5.2.1. Sử dụng `navigation` để mở `Drawer Menu`
Để mở `Drawer Menu`, chúng ta sử dụng props `navigation` được truyền vào component để gọi phương thức `openDrawer` hoặc `toggleDrawer`:

> Ví dụ: Mở `Drawer Menu` từ `CategoryScreen`:
```js
import React from 'react';
import { View, Text, Button } from 'react-native';

const CategoryScreen = ({ navigation }) => {
  return (
    <View>
      <Text>Category Screen</Text>
      <Button title="Open Drawer" onPress={() => navigation.openDrawer()} />
    </View>
  );
};
```

### 5.2.2. Sử dụng `options` `drawerLabel` và `drawerIcon` để thiết lập `Label` và `Icon` cho `Drawer Menu`
Để thiết lập `Label` và `Icon` cho `Drawer Menu`, chúng ta sử dụng `options` trong `Drawer.Screen` với thuộc tính `drawerLabel` và `drawerIcon`:
- `drawerLabel`: Thiết lập `Label` cho `Drawer Menu`.
- `drawerIcon`: Nhận vào 1 function với đầu vào là object chứa `color`, `size`,... (Đây là các thuộc tính của `Drawer.Navigator`) trả về `React Element` chứa `Icon` cho `Drawer Menu`.
> Ví dụ: Thiết lập `Label` và `Icon` cho `CategoryScreen`:
```js
...
<Drawer.Screen
  name="Category"
  component={CategoryScreen}
  options={{
    drawerLabel: 'Categories',
    drawerIcon: ({color, size}) => (
      <Ionicons name="ios-restaurant" size={size} color=color />
    ),
  }}
/>
```

> Ví dụ hoàn chỉnh sử dụng `Drawer Navigator`:
```js
<Drawer.Navigator
      screenOptions={{
        headerStyle: { backgroundColor: "#351401" }, // Màu header
        headerTintColor: "white", // Màu chữ header
        sceneContainerStyle: { backgroundColor: "#3f2f25" }, // Màu nền màn hình
        drawerContentStyle: { backgroundColor: "#351401" }, // Màu nền drawer
        drawerInactiveTintColor: "white", // Màu chữ drawer khi không active
        drawerActiveTintColor: "#351401", // Màu chữ drawer khi active
        drawerActiveBackgroundColor: "#e4baa1", // Màu nền drawer khi active
      }}
    >
      <Drawer.Screen
        name="Categories" // Tên màn hình
        component={CategoryScreen} // Component sẽ render ra màn hình
        options={{

          title: "All Categories", // Tiêu đề của màn hình
          drawerIcon: (
            { color, size } // Icon của màn hình, color và size được truyền vào từ Drawer.Navigator, 1 function trả về 1 component
          ) => (
            <Ionicons name="list" color={color} size={size} /> // Icon sử dụng Ionicons, name là tên icon, color và size được truyền vào từ Drawer.Navigator
          ),
        }}
      />
      <Drawer.Screen
        name="Favorites" // Tên màn hình

          ),
        }}
      />
    </Drawer.Navigator>
```

## 6. Sử dụng `Bottom Tab Navigator` để hiển thị `Tab Menu` dưới cùng
`Bottom Tab Navigator` là một trong những cơ chế điều hướng phổ biến nhất trong `React Navigation`, cho phép chúng ta hiển thị `Tab Menu` dưới cùng của ứng dụng.

`Bottom Tab Navigator` sẽ tự tạo ra `Tab Menu` dưới cùng khi chúng ta đăng ký các `màn hình` vào `Bottom Tab Navigator`.

### 6.1. Cài đặt `Bottom Tab Navigator`
Để cài đặt `Bottom Tab Navigator`, chúng ta sử dụng lệnh sau:
```bash
npm install @react-navigation/bottom-tabs
```

### 6.2. Sử dụng `Bottom Tab Navigator`
Sử dụng `Bottom Tab Navigator` tương tự như `Stack Navigator`, chúng ta cũng cần `import` component `createBottomTabNavigator` từ thư viện `@react-navigation/bottom-tabs` và tạo một `Bottom Tab Navigator` component mới từ `createBottomTabNavigator` trong file `App.js`:

> App.js
```js
...
import { createBottomTabNavigator } from '@react-navigation/bottom-tabs';
const Tab = createBottomTabNavigator();
```

`Tab` Component được tạo ra từ `createBottomTabNavigator` chứa 2 component con là:
- `Tab.Navigator`: Component cha chứa các màn hình con. Nó có các `thuộc tính` phổ biến sau:
    + `initialRouteName`: Điền `Tên` của màn hình mặc định khi ứng dụng khởi chạy. (Tab.Screen đầu tiên sẽ là màn hình mặc định).
    + `screenOptions`: Chứa 1 object các `tùy chọn` cho các màn hình con. Như: `headerStyle`, `headerTintColor`, `contentStyle`.
- `Tab.Screen`: Component con chứa màn hình con. Có các thuộc tính phổ biến sau:
    + `name`: Tên của màn hình.
    + `component`: Component hiển thị của màn hình.
    + `options`: Chứa 1 object các `tùy chọn` cho màn hình. Như: `headerTitle`, `headerShown`, `headerStyle`, `headerTintColor`, `title`, `tabBarLabel`, `tabBarIcon`.

Tất cả quy tắc sử dụng `Bottom Tab Navigator` tương tự như `Stack Navigator`, chỉ khác là `Bottom Tab Navigator` sẽ hiển thị `Tab Menu` dưới cùng của ứng dụng.

### 6.2.1. Sử dụng `navigation` để chuyển đổi giữa các `Tab`
Để chuyển đổi giữa các `Tab`, chúng ta sử dụng props `navigation` được truyền vào component để gọi phương thức `navigate`:

> Ví dụ: Chuyển đổi giữa các `Tab` từ `CategoryScreen`:
```js
import React from 'react';
import { View, Text, Button } from 'react-native';

const CategoryScreen = ({ navigation }) => {
  return (
    <View>
      <Text>Category Screen</Text>
      <Button title="Go to Favorites" onPress={() => navigation.navigate('Favorites')} />
    </View>
  );
};
```

### 6.2.2. Sử dụng `options` `tabBarLabel` và `tabBarIcon` để thiết lập `Label` và `Icon` cho `Tab Menu`
Để thiết lập `Label` và `Icon` cho `Tab Menu`, chúng ta sử dụng `options` trong `Tab.Screen` với thuộc tính `tabBarLabel` và `tabBarIcon`:
- `tabBarLabel`: Thiết lập `Label` cho `Tab Menu`.
- `tabBarIcon`: Nhận vào 1 function với đầu vào là object chứa `color`, `size`,... (Đây là các thuộc tính của `Tab.Navigator`) trả về `React Element` chứa `Icon` cho `Tab Menu`.
> Ví dụ: Thiết lập `Label` và `Icon` cho `CategoryScreen`:
```js
...
<Tab.Screen
  name="Category"
  component={CategoryScreen}
  options={{
    tabBarLabel: 'Categories',
    tabBarIcon: ({color, size}) => (
      <Ionicons name="ios-restaurant" size={size} color={color} />
    ),
  }}
/>
```

> Ví dụ hoàn chỉnh sử dụng `Bottom Tab Navigator`:
```js
    <BottomTab.Navigator screenOptions={{ headerShown: false }} // Ẩn header
    >
      <BottomTab.Screen
        name="Favorites" // Tên màn hình
        component={FavoritesScreen} // Component sẽ render ra màn hình
        options={{ // Các options của màn hình
          tabBarIcon: ({ color, size }) => ( // Icon của màn hình, color và size được truyền vào từ BottomTab.Navigator, 1 function trả về 1 component
            <Ionicons name="star" color={color} size={size} />
          ),
        }}
      />
    </BottomTab.Navigator>
```
---
> LƯU Ý: CẦN PHẢI KÍCH HOẠT `Navigation` TRONG ỨNG DỤNG TRƯỚC KHI SỬ DỤNG `BOTTOM TAB NAVIGATOR`. BẰNG CÁCH BỌC TOÀN BỘ ỨNG DỤNG BÊN TRONG `NavigationContainer`.
> LƯU Ý: KHI CHUYỂN SANG `MÀN HÌNH` KHÁC, CÁC `STATE` TRONG `MÀN HÌNH` HIỆN TẠI SẼ BỊ MẤT.


## 7. Kết hợp `Stack Navigator`, `Drawer Navigator`, `Bottom Tab Navigator` trong ứng dụng (Lồng Navigator trong nhau)
Chúng ta có thể kết hợp `Stack Navigator`, `Drawer Navigator`, `Bottom Tab Navigator` trong ứng dụng bằng cách lồng các `Navigator` trong nhau.

Để lồng `Navigator` trong nhau, chúng ta cần tạo ra các `Navigator` con và đăng ký vào `Navigator` cha thông qua thuộc tính `component` của `Navigator` cha.

Ví dụ: Kết hợp `Stack Navigator`, `Drawer Navigator`, `Bottom Tab Navigator` trong ứng dụng:
```js
const Stack = createNativeStackNavigator();
const Drawer = createDrawerNavigator();
const BottomTab = createBottomTabNavigator();

const DrawerNavigator = () => {
  return (
    <Drawer.Navigator
      screenOptions={{
        headerStyle: { backgroundColor: "#351401" }, // Màu header
        headerTintColor: "white", // Màu chữ header
        sceneContainerStyle: { backgroundColor: "#3f2f25" }, // Màu nền màn hình
        drawerContentStyle: { backgroundColor: "#351401" }, // Màu nền drawer
        drawerInactiveTintColor: "white", // Màu chữ drawer khi không active
        drawerActiveTintColor: "#351401", // Màu chữ drawer khi active
        drawerActiveBackgroundColor: "#e4baa1", // Màu nền drawer khi active
      }}
    >
      <Drawer.Screen
        name="Categories" // Tên màn hình
        component={CategoryScreen} // Component sẽ render ra màn hình
        options={{
          // Các options của màn hình
          title: "All Categories", // Tiêu đề của màn hình
          drawerIcon: (
            { color, size } // Icon của màn hình, color và size được truyền vào từ Drawer.Navigator, 1 function trả về 1 component
          ) => (
            <Ionicons name="list" color={color} size={size} /> // Icon sử dụng Ionicons, name là tên icon, color và size được truyền vào từ Drawer.Navigator
          ),
        }}
      />
      <Drawer.Screen
        name="FavoritesDrawer" // Tên màn hình
        component={BottomTabNavigator} // Component sẽ render ra màn hình
        options={{
          title: "Favorites",
          // Các options của màn hình
          drawerIcon: (
            { color, size } // Icon của màn hình, color và size được truyền vào từ Drawer.Navigator, 1 function trả về 1 component
          ) => (
            <Ionicons name="star" color={color} size={size} /> // Icon sử dụng Ionicons, name là tên icon, color và size được truyền vào từ Drawer.Navigator
          ),
        }}
      />
    </Drawer.Navigator>
  );
};

const BottomTabNavigator = () => {
  return (
    <BottomTab.Navigator screenOptions={{ headerShown: false }} // Ẩn header
    >
      <BottomTab.Screen
        name="Favorites" // Tên màn hình
        component={FavoritesScreen} // Component sẽ render ra màn hình
        options={{ // Các options của màn hình
          tabBarIcon: ({ color, size }) => ( // Icon của màn hình, color và size được truyền vào từ BottomTab.Navigator, 1 function trả về 1 component
            <Ionicons name="star" color={color} size={size} />
          ),
        }}
      />
      <BottomTab.Screen
        name="Tab1"
        component={Tab1}
        options={{
          tabBarIcon: ({ color, size }) => (
            <Ionicons name="star" color={color} size={size} />
          ),
        }}
      />
      <BottomTab.Screen
        name="Tab2"
        component={Tab2}
        options={{
          tabBarIcon: ({ color, size }) => (
            <Ionicons name="star" color={color} size={size} />
          ),
        }}
      />
    </BottomTab.Navigator>
  );
};

export default function App() {
  return (
    <>
      <StatusBar style="light" />
      <NavigationContainer>
        <Stack.Navigator
          initialRouteName="Categories"
          screenOptions={{
            headerStyle: {
              backgroundColor: "#351401",
            },
            headerTintColor: "white",
            contentStyle: {
              backgroundColor: "#3f2f25",
            },
          }}
        >
          <Stack.Screen
            name="Drawers"
            component={DrawerNavigator}
            options={{
              headerShown: false,
            }}
          />
          <Stack.Screen
            name="MealsOverview"
            component={MealsOverviewScreen}
            options={{
              title: "Meals Overview",
            }}
          />
          <Stack.Screen name="MealDetails" component={MealDetailScreen} />
        </Stack.Navigator>
      </NavigationContainer>
    </>
  );
}
```

NHƯ VẬY, TRONG MÀN HÌNH ĐĂNG KÝ LÀ `STACK NAVIGATOR` ĐẦU TIÊN CHÚNG TA CÓ `DRAWER NAVIGATOR`, VÀ TRONG MÀN HÌNH ĐĂNG KÝ THỨ 2 CỦA `DRAWER NAVIGATOR` CHÚNG TA CÓ `BOTTOM TAB NAVIGATOR`.

> LƯU Ý: MỖI MỘT MÀN HÌNH `SCEEN` CHỈ CÓ THỂ ĐĂNG KÝ TRONG 1 `NAVIGATOR` (STACK, DRAWER, BOTTOM TAB, TOP TAB).
