# Navigation trong React Native
## 1. Giới thiệu
`Navigation` là một phần quan trọng trong mọi ứng dụng di động, giúp người dùng dễ dàng di chuyển giữa các màn hình khác nhau. Trong React Native, chúng ta có nhiều thư viện hỗ trợ việc quản lý `Navigation`, trong đó có `React Navigation`.

Xem thêm tài liệu hướng dẫn tại đây: [React Navigation](https://reactnavigation.org/docs/getting-started/)

## 2. Cài đặt React Navigation
Để cài đặt `React Navigation`, chúng ta sử dụng lệnh sau:
```bash
npm install @react-navigation/native
```

Tiếp theo, chúng ta cần cài thêm các thư viện sau, mặc định khi sử dụng `React Navigation` thì `Safe Area` sẽ được tự động thiết lập mà không cần tuỳ chỉnh thêm bằng tay.
> Nếu sử dụng `Expo`:
```bash
npx expo install react-native-screens react-native-safe-area-context
```
> Nếu sử dụng `React Native CLI`, chúng ta có lệnh chạy sau:
```bash
npm install react-native-screens react-native-safe-area-context
```

> NGOÀI RA `REACT NATIVE` CẦN CÓ CÁC THƯ VIỆN ĐỂ HỖ TRỢ `REACT NAVIGATION` THEO CÁC CƠ CHẾ NHƯ: `STACK`, `NATIVE STACK`, `DRAWER`, `BOTTOM TAB`, `MATERIAL TOP TAB`, `MATERIAL BOTTOM TAB`. CHI TIẾT HƯỚNG DẪN CÀI ĐẶT CÁC THƯ VIỆN NÀY Ở PHẦN SAU.

## 3. Kích hoạt Navigation trong ứng dụng
Sau khi cài đặt thư viện `@react-navigation/native`, chúng ta cần kích hoạt `Navigation` trong ứng dụng bằng cách `import` component `NavigationContainer` từ thư viện `@react-navigation/native` và bọc toàn bộ ứng dụng bên trong `NavigationContainer` trong file `App.js`:
> App.js
```js
...
import { NavigationContainer } from '@react-navigation/native';

export default function App() {
  return (
    <NavigationContainer>
      ... // Logic, Component khác của ứng dụng
    </NavigationContainer>
  );
}
```
